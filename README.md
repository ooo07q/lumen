# Lumen

[English](README.en.md)

你照常寫筆記、剪網頁、放 PDF，在 Lumen 裡按一下，AI 就讀完筆記：替每篇寫一頁來源頁，把裡面的人物、概念各自整理成一頁並互相連結，找出筆記之間說法衝突的地方；你問問題，它從這些頁面回答並附上出處。整理出來的頁面放在同一個資料夾的 `wiki/` 裡，你寫的原文一字不改。

筆記庫就是一個普通資料夾，Obsidian 的 vault 也可以直接打開。

編輯筆記像 iPhone 的備忘錄：畫面上直接看到標題、粗體、清單、核取清單和表格，不會出現 `#` 或 `**` 這些符號。檔案照樣存成 Markdown，你沒動過的行一字不改。

## 安裝與啟動

需要 macOS 和 Python 3（系統內建的就可以）。

```
git clone https://github.com/ooo07q/lumen.git ~/Lumen
python3 ~/Lumen/server.py --open
```

瀏覽器會打開 Lumen。第一次會問你要建立新的筆記庫，還是打開一個現有的資料夾。

終端機印出的網址帶著一組存取碼（`http://127.0.0.1:8765/?k=…`）。用它打開一次，瀏覽器之後就記得；別的網站因此沒辦法透過你的瀏覽器讀筆記。

| 參數 | 作用 |
|---|---|
| `--vault 路徑` | 直接打開這個資料夾 |
| `--read-only` | 只看，不寫入任何檔案 |
| `--port 8765` | 換埠號；被占用時自動找空的 |

PDF 要轉成筆記才能整理。第一次放進 PDF 時，Lumen 會問要不要轉；按「轉成筆記」，它會先下載轉檔工具（[uv](https://docs.astral.sh/uv/)，裝在 Lumen 自己的資料夾，大約一兩分鐘，只要一次），之後的 PDF 都自動轉。

介面有繁體中文、简体中文和 English，預設跟系統語言一樣；點左上角的筆記庫名稱可以切換。

## 連接 AI

點左上角的筆記庫名稱 →「連接 AI」。Lumen 用你自己的訂閱，不經手帳號密碼，用量算在你的方案裡。

| 服務 | 用途 | 需要 |
|---|---|---|
| Claude Code | 回答問題、整理知識庫 | Claude 訂閱（Pro、Max）。還沒裝 Claude Code 的話，Lumen 用 Anthropic 官方安裝程式裝好，再帶你到瀏覽器登入 |
| ChatGPT | 回答問題、整理知識庫 | ChatGPT 付費方案（Go、Plus、Pro） |
| Jev（TypeSafe） | 找相關的頁、挑出筆記的重點段落、判斷長篇從哪裡分段、檢查整理結果 | TypeSafe API 金鑰，費用很低。不連的話搜尋改用關鍵字 |

Claude Code 和 ChatGPT 至少連一個。

## 整理一篇筆記

打開筆記，按右欄的「請 AI 整理這篇」。每次整理分兩步：

1. AI 先讀筆記、查知識庫裡相關的頁，列出這篇的重點，以及要新增、更新哪些頁。這一步只讀不寫。
2. 你看過計畫，可以寫下要改的地方，再按「照這樣做」。AI 寫好來源頁、更新相關的頁，做完列出每個改過的檔案和差異。

不滿意就按「全部復原」，這次的修改會一次放回去。

AI 讀的是重點段落。Jev 替每一段評分，挑出撐起全篇大約八成重點的段落交給 AI；沒挑上的段落留下一句主旨，AI 需要時可以回去讀。以一章書來說，交出去的文字大約只有一半。想讓 AI 讀全文，在計畫下面寫「整篇讀」，AI 會自己判斷、向 Lumen 要全文（長篇仍然只讀這一部分）。

重點多到一頁來源頁裝不下的長篇，Lumen 會按內容分部分整理：Jev 判斷哪裡開始新的主題或章節，每部分大約一章的份量，各寫一頁來源頁。清單會顯示「已整理 3/16」，全部整理完才算完成；筆記中途改過，進度也會保留。拿同一本書的三章測試，分三次整理抓到的重點比一次整理整篇多。

## 其他功能

- 問 AI：在上面的搜尋框打問題按 ⌘↵。Lumen 先找出相關的頁，連同打開的筆記交給 AI，回答的每個說法都標出處，可以點過去。
- 待整理清單：還沒整理的筆記照 Jev 建議的順序排。放進附件資料夾（新筆記庫是 `Attachments/`，Obsidian 設定的附件資料夾也算）的 PDF 會轉成筆記排進來。
- 潛在連結和矛盾：右欄列出這篇提到、卻還沒連過去的頁；兩個來源對同一件事說法衝突時，可以並排比較。
- 版本紀錄：每次儲存前留下前一版，可以比較、還原。
- 日記：「＋ 今天的日記」。日記只留在這台電腦，不送 AI，也不送 Jev。

## 資料放在哪

| 東西 | 位置 |
|---|---|
| 你的筆記 | 筆記庫資料夾裡，`wiki/` 以外的全部 |
| AI 整理的頁 | 筆記庫的 `wiki/` |
| 版本紀錄 | 筆記庫的 `.lumen/history/` |
| 刪掉的檔案 | 筆記庫的 `.trash/`（和 Obsidian 共用，可以復原） |
| 設定、登入、快取 | `~/Library/Application Support/Lumen/` |

伺服器只聽本機（127.0.0.1），讀寫都要存取碼。

## AI 能做和不能做的事

- 只能寫 `wiki/`。你的筆記、附件、PDF 不能改、搬、刪；做完 Lumen 會檢查 `wiki/` 以外有沒有檔案變動。
- 讀不到日記，也讀不到從日記整理出來的頁。
- 沒有終端機、沒有網路，只能用 Lumen 提供的固定工具。
- 不讀筆記庫裡的 CLAUDE.md，也不載入你自己的 Claude Code 設定。
